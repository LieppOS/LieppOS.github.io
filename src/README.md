# LieppOS research wiki

Open research and engineering documentation for the **Ulefone Armor 29 Pro Thermal (GQ5012BF1)**.

The site is generated with [mdBook](https://rust-lang.github.io/mdBook/) and hosted using GitHub Pages. The authoritative research and source documents live in [LieppOS/LieppOS-ulefone-gq5012bf1-research](https://github.com/LieppOS/LieppOS-ulefone-gq5012bf1-research).

## Where to begin

- **[Understanding evidence](evidence.md)** explains the difference between discovery, configuration, build validation and device runtime validation.
- **Research archive** appears in the navigation after importing the public research repository.
- **[LieppOS GitHub organization](https://github.com/LieppOS)** contains associated projects and source code.

> Documentation is exploratory and may include hypotheses, unsuccessful experiments, and device-specific findings. Always check the original document and its validation status before using technical procedures, particularly ones involving bootloaders and partitions.
